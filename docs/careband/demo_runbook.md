# CareBand v0.2 三分钟比赛 Demo Runbook

演示目标：用一条可重复链路证明“真实/半真实每日聚合 + 规范 SOS + 规则风险 + 三端 Agent 摘要 + 人工任务闭环”。不在三分钟内新增记忆陪伴、真实 ASR/TTS 或医疗能力。

## 角色与设备

| 角色 | 职责 |
| --- | --- |
| 主讲人 | 叙事、切换机构 / 长者 / 家属页面 |
| 操作人 | 重置 Demo、导入数据、触发按钮、接单与完成 |
| 观察人 | 盯服务状态、Provider 标签、计时和 fallback，必要时切备用 |

实物未通过三轮验收前，主讲人必须说“这是软件模拟的同一事件契约”；不能拿网页按钮冒充实体原型。

## 演示前 15 分钟

- [ ] 使用固定本地分支和固定虚构 E001 数据，不临场改代码。
- [ ] 一键启动后确认前端、后端、SQLite、QwenPaw 健康状态。
- [ ] 执行 `/api/demo/reset`，确认保留 TEST001，E001–E004 事件/任务已复位。
- [ ] 同一 CSV 重导不会增加重复日期，质量 `85` 在页面显示 `85%`。
- [ ] 先跑一次真实 Agent；记录当前 Provider、模型、验证状态和耗时。
- [ ] 再断开 Agent 跑一次 fallback，确认标签明确且链路完成。
- [ ] 硬件已通过三轮验收才连接；否则使用网页模拟器并准备实物说明页。
- [ ] 本地完整链路连续跑三次，保存每轮时间和结果。
- [ ] 打开备用录屏、截图、固定 JSON 和本 runbook；关闭系统通知。

## 180 秒主线

### 0:00–0:20 问题与机构全局

画面：机构端多长者状态，团队测试者 TEST001 不计入运营人数。

旁白：

> 照护团队需要的不是更多原始数据，而是知道谁需要先处理、为什么，以及处理后家属是否得到可信更新。CareBand 把每日聚合与求助事件变成可追溯的照护闭环。

可见证据：机构人数、六级状态、非医疗声明。

### 0:20–0:45 E001 数据与个人基线

画面：进入陈伯 E001；显示最近七个不同日期、数据来源、同步时间、完整度和质量。

旁白：

> 数据先标准化为 DailySnapshot，缺失值保持空，不把原始 Apple Health 文件发给模型。风险比较的是个人七日基线，而不是一个武断的统一阈值。

可见证据：`data_source`、85%、基线不含当天。

### 0:45–1:05 触发规范 SOS

画面：实物长按（仅验收通过后）或网页硬件模拟器；旁边显示规范请求。

旁白：

> 长按只上传 `event_type=sos`，按钮动作保存在 payload。硬件不决定风险，后端也不接受前端伪造的风险结果。

可见证据：事件 ID、`source=esp32` 或明确 `mock`、`button_pattern=long_press`。

### 1:05–1:30 规则先行与真实 Agent

画面：风险升为 `urgent`，原因与证据；Agent 运行标签。

旁白：

> 规则引擎先把 SOS 判为紧急，再由 Agent 用同一个结果生成护工、家属和机构摘要。输出必须通过 JSON Schema，并且不能改变风险等级或给出诊断、处方。

可见证据：规则理由、Provider / 模型、验证通过、耗时；若 fallback，直接说明原因。

### 1:30–2:10 护工到家属闭环

画面：护工任务 `open → acknowledged → in_progress → resolved`；切家属安心卡。

旁白：

> 护工接单、处理中和完成都由人确认。完成任务会解决关联事件，旧 SOS 不会永久维持风险；家属只看到必要的跟进状态，不默认看到精确位置或原始语音。

可见证据：同一任务 ID、处理人/备注、家属“已跟进”。

### 2:10–2:35 回到机构与数据隔离

画面：机构统计刷新；TEST001 团队数据证据仍在，但不计入服务对象指标。

旁白：

> 同一份已验证摘要驱动三端页面，机构看到完成情况而不是三套相互矛盾的文案。团队 Apple Watch 资料保留为数据链路证据，但不会污染机构运营数字。

### 2:35–2:55 主动展示降级

画面：fallback 矩阵或已准备的断 Agent 结果。

旁白：

> 外部模型不是单点故障。超时、非法 JSON 或风险被篡改时，系统重试一次，再明确显示 Mock fallback；规则、任务和家属更新继续工作。

### 2:55–3:00 收束

旁白：

> 我们现在证明的是一条可运行、可解释、可降级的照护闭环，不是医疗诊断，也不夸大尚未完成的试点。

## 现场切换规则

- 任何步骤 5 秒内无响应，观察人报出故障类型，操作人按 `fallback_matrix.md` 切备用；主讲人继续解释真实边界。
- Agent 标签是 Mock 时绝不说“真实 QwenPaw 已生成”。
- 硬件无 HTTP 2xx 时绝不说“按钮已成功上传”；切网页模拟并说明。
- 不展示密钥、终端环境变量、真实联系人或真实健康原始数据。

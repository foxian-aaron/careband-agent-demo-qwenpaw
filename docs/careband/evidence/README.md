# Local synthetic evidence fixtures

These files contain only the fictional E001 demo persona and are safe backup
materials for the local competition demo. They are contract fixtures, not proof
of a real elder, a physical ESP32, or a live QwenPaw call.

- `E001-daily-snapshots.csv` is the fixed seven-day CSV used by the import story.
- `sos-request-and-rule-result.json` records the normalized SOS request and the
  deterministic server assertions exercised by the API and browser gates.

The corresponding UI captures are stored under `deliverables/screenshots/`.

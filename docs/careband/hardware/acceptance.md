## 其他交互与故障降级

- [ ] 短按只生成 `medication` + `action=confirmed`，不生成 SOS。
- [ ] 三连按只生成一次 `sos` + `button_pattern=triple_click`。
- [ ] 双击不上传，串口明确记录忽略。
- [ ] 断开 Wi-Fi 后 SOS 留在 RAM 队列，红灯闪烁且不会显示“成功”。
- [ ] 恢复 Wi-Fi 后同一 `event_id` 上传成功，未产生重复任务。
- [ ] 7 条非紧急事件后仍可加入 1 条 SOS；非紧急事件不能占用保留槽。
- [ ] 队列满且含非紧急事件时，新 SOS 淘汰最早非紧急事件并保留；8 条全为 SOS 时才拒绝第 9 条。
- [ ] HTTP 400/404 被明确拒绝并移出队列，下一条 SOS 仍能上传；网络错误和 5xx 才重试。
- [ ] 队列拒绝时紫灯/四次震动，日志明确“未存储”，不伪装成功。
- [ ] 设备重启前后生成的 `event_id` boot nonce 不同。
- [ ] 设备重启会清空 RAM 队列的限制已向演示人员说明。

## 录制规范

- 1920×1080，浏览器缩放与系统字体在开录前锁定；全片用同一窗口尺寸。
- 只录应用与必要架构图；裁掉终端密钥、用户名、真实路径、联系人和浏览器通知。
- 鼠标动作慢、单一；每次点击后至少停 1 秒让状态可读。
- Provider 真实可用时保留一次完整实时调用；不稳定时用已录制的真实调用片段，并标注录制时间。
- fallback 是产品能力，不用剪辑隐藏。
- 原型实物镜头必须显示同一轮串口 event ID 和网页任务；否则只作为外观 B-roll，不证明闭环。

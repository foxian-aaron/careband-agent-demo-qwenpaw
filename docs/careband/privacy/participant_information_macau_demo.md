# CareBand 澳门 Demo / 访谈参与者说明（草案）

版本：v0.2 草案
适用：团队成员、工作人员、护工/家属/机构代表的需求访谈与软件演示
不适用：真实长者试戴、医疗测试、生产服务

> 本文件是产品研究的工作模板，不构成法律意见，也不表示已经完成澳门或其他地区的正式合规审查。正式招募、录音、公开传播或真实长者参与前，应由负责人和具备相应资格的本地专业人士复核。

## 1. 活动目的

CareBand 是一个长者照护流程原型。我们希望了解：穿戴聚合数据、SOS 按钮、规则风险提示和三角色摘要，能否帮助护工、家属与机构更快理解并跟进照护信号。

这次活动不会诊断疾病，不会建议调整药量，不测试医疗器械性能，也不会要求真实长者试戴。演示默认使用虚构的 E001“陈伯”和模拟/团队测试聚合数据。

## 2. 参与内容

预计约 30 分钟：

1. 观看网页或按钮原型演示；
2. 描述当前照护流程、痛点和信任顾虑；
3. 对界面、任务和通知方式提出意见；
4. 可自愿决定是否允许记笔记、录音、录像或匿名引用。

参与完全自愿。可以跳过任何问题、暂停或随时退出，不需要说明理由，也不会因此受到不利影响。

## 3. 最少收集范围

| 数据 | 默认处理 | 不收集 / 不默认展示 |
| --- | --- | --- |
| 角色类型 | 记录为“护工/家属/机构代表/工作人员” | 非必要的身份证件、完整生日 |
| 访谈笔记 | 去标识化摘要，记录日期和场景 | 与研究目的无关的个人健康史 |
| 联系方式 | 仅在同意后用于后续联系，与笔记分开保存 | 向其他参与者公开 |
| 录音/录像 | 只有分项勾选同意后才进行 | 默认录制、后台持续录音 |
| 位置 | 最多记录“澳门某机构/线上”等区域级场景 | 精确轨迹、家庭住址 |
| 演示健康数据 | 使用虚构 E001 或团队成员已授权的每日聚合值 | 原始 Apple Health XML、生产长者档案 |

若谈话中出现真实个案，请使用泛化描述，避免姓名、床位号、电话、精确住址和可直接识别的健康细节。

## 4. AI 与风险边界

- 规则引擎决定 `risk_level`；AI 只整理、解释和生成角色化摘要。
- AI 输出必须经过固定结构验证，失败时显示 Mock fallback。
- 所有提示都是照护风险信号，不是医疗、心理或用药诊断。
- 紧急情况应按现场既有应急程序和当地紧急渠道处理，不能等待 Demo 系统。

## 5. 访问、保存与分享

- 团队仅允许与本活动直接相关的成员访问去标识化资料。
- 联系方式与研究笔记应分开保存；高风险事件操作应保留审计记录。
- 未经单独同意，不在路演、社交媒体、参赛视频或对外材料中使用可识别的声音、画面或原话。
- 保留期限由项目负责人在活动前填写；到期后删除或匿名化，不能留空后无限期保存。

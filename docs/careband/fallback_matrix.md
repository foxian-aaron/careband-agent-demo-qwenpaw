# CareBand 现场 Fallback 矩阵

原则：降级必须可见，不静默伪装真实服务，不让客户端或 Agent 接管风险判断。

| 故障 | 现场识别 | 自动行为 | 操作人动作（≤5 秒） | 主讲人一句话 | 不能声称 |
| --- | --- | --- | --- | --- | --- |
| QwenPaw 离线 / 超时 | Agent meta 显示失败与耗时 | 重试一次后确定性 Mock | 保持页面，指出 `Mock fallback` 标签 | “规则和任务仍工作，摘要明确降级。” | “这是实时 QwenPaw 输出” |
| Agent 非法 JSON / Schema 错误 | 验证状态失败 | 带错误修复一次，再 Mock | 展开验证结果或用固定截图 | “模型不能绕过固定结构。” | “AI 自己决定了风险” |
| Agent 篡改风险 | 风险一致性检查失败 | 拒绝输出，再 Mock | 对比规则结果与拒绝原因 | “风险以规则结果为准。” | “模型提高/降低了风险” |
| 外网中断 | Provider 失败；本地 API 仍健康 | 本地规则 + Mock 继续 | 不重启全套服务 | “核心闭环不依赖外网可用。” | “全部在线服务正常” |
| 后端未启动 | 健康检查失败、前端请求错误 | 前端显示离线而非假成功 | 启动脚本重试一次；仍失败切预录 | “现在展示同版本的完整预录。” | “刚才事件已入库” |
| SQLite 写入失败 | API 5xx / 审计无记录 | 请求失败，不更新成功状态 | 切固定只读演示或预录 | “没有持久化证据就不算闭环成功。” | “任务已经保存” |
| ESP32 未连接 Wi-Fi | 黄灯 / 串口连接重试 | SOS 留 RAM，红灯闪 | 切网页模拟器并标“软件模拟” | “模拟器发送同一规范事件。” | “实体按钮已上传” |
| ESP32 网络错误 / HTTP 5xx | 串口非 2xx、队列未清 | RAM 指数退避重试 | 等一次重试；超 5 秒切模拟器 | “硬件事件尚未送达，我们不显示假成功。” | “服务端已收到” |
| ESP32 HTTP 4xx / 3xx | `upload_rejected_not_retried`、紫灯闪烁 | 移出该事件，不阻塞下一条 SOS | 修正 URL/负载后重新触发；现场切模拟器 | “请求被明确拒绝，没有伪装成功。” | “系统稍后会自动补传” |
| ESP32 非紧急保留槽 / 全 SOS 队列已满 | 紫灯、明确未存储日志 | 为 SOS 保留第 8 槽；满队列 SOS 淘汰最早非紧急事件 | 若 8 条全为 SOS，立即改用人工/网页求助并恢复网络 | “原型优先保护 SOS，并明确暴露剩余容量限制。” | “所有事件都会自动补传” |
| 实物损坏 / 无 COM 口 | 无串口/无法上电 | 无 | 使用软件版镜头和未勾选验收表 | “实物闭环仍待验收。” | “硬件已连续通过三次” |
| CSV 格式错误 | preview warnings / confirm 禁用 | 不写入数据库 | 用固定、已验证 CSV | “错误在确认导入前被拦截。” | “坏数据已经导入” |
| CSV 重复导入 | 相同 elder/date | 幂等覆盖 | 展示日期数未增加 | “同日重导不会制造重复趋势。” | “这是两个不同日期” |
| 数据质量低 / 无快照 | `data_insufficient` | 不默认稳定 | 解释佩戴时长与缺失字段 | “数据不足不是稳定。” | “老人状态正常” |
| 浏览器页面卡住 | UI 不刷新、API 健康 | 无 | 刷新一次；仍失败切备用窗口/视频 | “后端证据仍可追溯。” | “刚才页面实时更新” |
| Demo 数据污染 | reset 后仍有旧任务 | 不继续正式演示 | 停止、重置并核对 E001；用预录兜底 | “我们先恢复可重复基线。” | “旧事件属于本轮” |

# Public evidence policy

- Evidence committed to this directory must be manually redacted before staging.
- Never include complete chats, tokens, cookies, usernames in local paths, raw health data, raw voice text, or precise location.
- Screenshots must be compressed below 1 MiB. The repository boundary scanner intentionally rejects every larger file for explicit review.
- Machine-readable manifests should contain hashes, test results, run IDs, and provider labels rather than sensitive source material.

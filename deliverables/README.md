# CareBand v0.2 可编辑交付物

- `CareBand_v0.2_pitch_deck.pptx`：9 页可编辑路演 PPT。内容只使用本地实现与自动测试证据；没有把模板、计划或未完成试点写成成果。
- `CareBand_v0.2_software_demo.mp4`：1920×1080、30 fps、2:13 的真实本地软件操作录屏，覆盖机构端、个人基线、CSV 预览/确认/历史、SOS、Agent fallback、护工闭环、家属安心卡与机构 1/1 跟进统计。录制时阿里凭据已失效，因此画面如实显示 Mock fallback；视频不含旁白，也不证明实体硬件闭环。
- `CareBand_v0.2_180s_silent_storyboard.mp4`：1920×1080、30 fps、3:00 的无旁白路演故事板。它不是实时 UI 操作录屏，也不证明实体硬件已经闭环。

正式提交视频时，可按 `docs/careband/shot_list_180s.md` 为软件录屏补团队片头、旁白与经同意的出镜素材；只有实体硬件三轮验收通过后，才加入按钮、LED、串口和网页同框镜头。团队名称、成员、旁白和主办方素材仍需用户提供。
